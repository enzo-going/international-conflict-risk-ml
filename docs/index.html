Sistema de Machine Learning de Análise Preditiva de Conflitos Internacionais

Projeto experimental aplicado a dados históricos e heterogêneos em estrutura país-ano, com pipeline de dados, baseline, engenharia de features, modelos supervisionados e avaliação temporal para análise preditiva de conflitos em contexto de Big Data.

1. Formulação do problema

A motivação original do projeto envolve a análise de tensões internacionais, escalada de conflitos e risco de grandes crises globais, até um possível desencadeamento de uma Terceira Guerra Mundial. Porém após diversas análises e debates entre os desenvolvedores do projeto foi concluido que, seria metodologicamente frágil a sustentação dessa possível tese, pois além de ser um evento raro, é complexo de definir métricas e paramêtros relevantes, e seria necessário uma quantida de amostras históricas suficientes para treinamento supervisionado. Por isso, o problema foi reformulado para uma tarefa observável de Machine Learning: estimar através de big data, se a tendência é ter mais ou menos conflitos.

Pergunta de pesquisa operacional:
Dado o histórico de violência organizada e, futuramente, indicadores socioeconômicos, políticos e militares de um país em determinado ano, é possível estimar a ocorrência de violência organizada no ano seguinte com desempenho superior a uma baseline simples de persistência?
A reformulação não abandona a motivação original sobre escalada global. Muito Pelo contrário, ela transforma uma ideia ampla em um problema técnico mensurável, permitindo que o projeto avance de forma científica antes de propor qualquer índice agregado de risco sistêmico.

2. Arquitetura técnica do sistema

O projeto está sendo estruturado como um pipeline reprodutível de dados e Machine Learning, não apenas como um notebook isolado. Cada etapa transforma dados históricos em variáveis utilizáveis para modelagem preditiva.

1
Fontes de dados heterogêneas
UCDP como base central e, nas próximas etapas, integração de indicadores socioeconômicos do World Bank e possíveis fontes geopolíticas/militares.
2
Padronização em país-ano
Todos os dados precisam ser convertidos para uma granularidade comum: country-year. Essa etapa permite combinar fontes diferentes.
3
Feature engineering
Criação de variáveis históricas, temporais, socioeconômicas e regionais para representar melhor o contexto de risco de cada país.
4
Modelagem supervisionada
Treinamento de modelos de classificação para estimar target_conflict_next_year, sempre comparando contra a baseline de persistência.
5
Avaliação temporal
Treino no passado e teste no futuro. Essa escolha evita avaliação artificialmente otimista e simula melhor o uso real do modelo.
6
Camada visual e interpretativa
Painel HTML para acompanhar resultados, explicar decisões metodológicas e, futuramente, visualizar um índice exploratório de escalada global.

6. Conclusão provisória

O achado central até este ponto é que conflitos internacionais, medidos como violência organizada, apresentam forte persistência temporal. Isso explica por que uma baseline simples já alcança F1-score alto.

A engenharia de features temporais adicionou algum ganho ao modelo, principalmente ao aumentar a capacidade de identificar casos positivos. Porém, o ganho ainda é modesto. Isso indica que trocar apenas o algoritmo não deve ser a principal estratégia de evolução.

Direção metodológica:
A próxima melhoria relevante deve vir da integração de dados heterogêneos, especialmente indicadores socioeconômicos por país-ano, para testar se variáveis externas ao histórico direto de conflito aumentam o poder preditivo do sistema.

8. Módulo futuro: termômetro experimental de escalada

Uma evolução futura do sistema pode ser a criação de um índice agregado de risco, apresentado como um termômetro exploratório de escalada global. Esse módulo não deve ser interpretado como previsão determinística de guerra mundial, mas como visualização agregada dos sinais estimados pelo modelo.

Ideia futura:
Agregar probabilidades previstas por país, região e ano para criar um indicador visual de tendência sistêmica. Esse indicador só deve ser exibido com porcentagens reais quando houver dados heterogêneos integrados, calibração adequada e validação metodológica.
Status atual: conceito em planejamento. O modelo atual ainda estima risco em nível país-ano, não uma probabilidade direta de Terceira Guerra Mundial.
